Research at NetML

Where AI meets network security.

We build AI methods for network security and efficient language-model systems: detecting threats, identifying devices, reducing noisy features, and making retrieved context more useful to LLMs.

Our focus

Four connected research directions.

Our projects connect network measurement, optimization, and language models to practical problems.

01 / Language models

LLMs for cybersecurity

We investigate LLMs for adaptive security systems, including IoT fingerprinting, incident classification, and honeypots. We also study long-context retrieval-augmented generation and adaptive context pruning.

02 / Insight

Optimization and explainable AI

We reduce redundancy in high-dimensional security telemetry while preserving classification performance. Genetic algorithms, Artificial Bee Colony optimization, feature selection, quantization, and SHAP help us refine models and explain their decisions.

Related papers

  • Automated IoT Fingerprinting with LLMs: Harnessing Explainable AI and Artificial Bee Colony Optimization

  • AI-Driven Genetic Algorithms for Enhanced Numeric Feature Quantization in IoT Device Fingerprinting for Threat Detection
  • Automated Network Incident Identification through Genetic Algorithm-Driven Feature Selection
  • Comparative Analysis of Feature Selection Algorithms for Automated IoT Device Fingerprinting
03 / Identification

Device, host, and OS fingerprinting

We identify devices, operating systems, and hosts from protocol headers and encrypted SSL/TLS metadata. Our work studies compact traffic representations, passive identification, and the robustness of multi-protocol fingerprinting.

Related papers

  • Automated Passive OS Fingerprinting with Genetic Algorithms: Multi-Protocol Analysis and Adversarial Considerations
  • Automated Host Identification Using SSL/TLS Traffic with SHAP and Artificial Bee Colony
  • AI-Driven Genetic Algorithms for Enhanced Numeric Feature Quantization in IoT Device Fingerprinting for Threat Detection
  • Comparative Analysis of Feature Selection Algorithms for Automated IoT Device Fingerprinting
  • Automated IoT Device Identification from Network Traffic
  • Operating System Fingerprinting via Automated Network Traffic Analysis
  • Operating System Classification Performance of TCP/IP Protocol Headers
04 / Detection

Automated network threat detection

We develop frameworks that identify malicious behavior from packet-level telemetry, including DNS botnets, DoS attacks, fast-flux networks, and OS scanning. Search-based feature selection and machine learning help uncover useful header-level representations.

Related papers

  • Automated Network Incident Identification through Genetic Algorithm-Driven Feature Selection
  • Automated Fast-flux Detection using Machine Learning and Genetic Algorithms

Project spotlight

Making long-context RAG more selective.

JMAP addresses the noisy, costly context that retrieval-augmented generation can pass to a reader model.

Accepted · LCFM @ NeurIPS 2026

JMAP: Joint Multi-Document Attention with Clustering-Based Adaptive Context Pruning for Retrieval-Augmented Generation

JMAP uses a 149M-parameter ModernBERT-base cross-encoder to score sentences across multiple retrieved documents together in one 8,192-token pass. Clustering the scores sets an adaptive pruning threshold, allowing it to remove distracting text while retaining evidence spread across documents.

In the paper's evaluation on HotpotQA, 2WikiMultihopQA, MuSiQue, and TriviaQA, the pruned context improved a Qwen3-8B reader's answer F1 over unpruned context on all four datasets.
