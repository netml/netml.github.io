  • Automated Network Threat Detection:

    We develop automated detection frameworks that identify malicious network behavior directly from packet-level telemetry. Our work focuses on DNS botnets, DoS attacks (HULK, GoldenEye), fast-flux networks, and OS scanning activity. Rather than relying on manually crafted signatures, we use search-based feature selection and machine learning models to discover discriminative header-level representations that adapt to evolving attack patterns.

    Papers published:

    • Automated Network Incident Identification through Genetic Algorithm-Driven Feature Selection
    • Automated Fast-flux Detection using Machine Learning and Genetic Algorithms


  • Device, Host, and Operating System Fingerprinting:

    We design automated fingerprinting systems capable of identifying devices, operating systems, and hosts using packet-level protocol headers and encrypted SSL/TLS metadata. Our research uses machine learning and search-based optimization to discover compact, highly discriminative traffic representations for passive identification. Recent work extends this line to multi-protocol operating system fingerprinting and examines adversarial considerations, while the broader goal remains improved device inventory, anomaly detection, and network visibility without dependence on expert-defined signatures.

    Papers published:

    • Automated Passive OS Fingerprinting with Genetic Algorithms: Multi-Protocol Analysis and Adversarial Considerations
    • Automated Host Identification Using SSL/TLS Traffic with SHAP and Artificial Bee Colony
    • AI-Driven Genetic Algorithms for Enhanced Numeric Feature Quantization in IoT Device Fingerprinting for Threat Detection
    • Comparative Analysis of Feature Selection Algorithms for Automated IoT Device Fingerprinting
    • Automated IoT Device Identification from Network Traffic
    • Operating System Fingerprinting via Automated Network Traffic Analysis
    • Operating System Classification Performance of TCP/IP Protocol Headers


  • Optimization-Driven Feature Reduction and Explainable AI:

    A central theme of our research is reducing informational redundancy in high-dimensional security telemetry while maintaining strong classification performance. We investigate genetic algorithms, Artificial Bee Colony optimization, feature-selection methods, and explainable AI techniques such as SHAP to discover compact representations, analyze model behavior, and guide feature reduction. These methods are applied across network incident detection, device and host fingerprinting, numeric feature quantization, and LLM-based classification.

    Papers published:

    • Automated IoT Fingerprinting with LLMs: Harnessing Explainable AI and Artificial Bee Colony Optimization
    • Automated Host Identification Using SSL/TLS Traffic with SHAP and Artificial Bee Colony
    • AI-Driven Genetic Algorithms for Enhanced Numeric Feature Quantization in IoT Device Fingerprinting for Threat Detection
    • Automated Network Incident Identification through Genetic Algorithm-Driven Feature Selection
    • Comparative Analysis of Feature Selection Algorithms for Automated IoT Device Fingerprinting


  • Large Language Models for Cybersecurity:

    We investigate how large language models can support adaptive and automated cybersecurity systems. Current work includes LLM-based IoT fingerprinting that combines explainable AI with Artificial Bee Colony optimization, as well as adaptive honeypot testbeds that use LLMs for dynamic intrusion engagement. This research explores how generative and language-model capabilities can be integrated with network-security analytics and optimization-driven methods.

    Papers published:

    • An LLM-Driven Adaptive Honeypot Testbed for Dynamic Intrusion Engagement
    • Automated IoT Fingerprinting with LLMs: Harnessing Explainable AI and Artificial Bee Colony Optimization
