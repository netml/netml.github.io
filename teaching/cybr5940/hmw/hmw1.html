HMW 1 – Squid Web Proxy Server Setup and File Carving

Before You Begin

For this lab, you need a working Ubuntu virtual machine.

Make sure you can:

  • Start and log in to your Ubuntu VM.
  • Access the Internet from the VM.
  • Open a terminal.
  • Use Firefox.

You will install and configure the Squid web proxy server, access a PDF through the proxy, locate the PDF in Squid’s cache, and recover the PDF from the cached data.

Part 1 – Installing Squid Web Proxy Server

1. Update Ubuntu Repository

Open a terminal and run:

sudo apt-get update

2. Install Squid

Run:

sudo apt-get install squid

If prompted to continue, enter Y.

Part 2 – Configuring Squid

3. Open the Squid Configuration File

Run:

sudo gedit /etc/squid/squid.conf

If gedit is not available, you may use another text editor installed on your Ubuntu system.

4. Modify the Access Rule

Find the following entry in the file:

http_access deny all

Replace it with:

http_access allow all

5. Enable the Squid Cache Directory

Find the following line:

#cache_dir ufs /var/spool/squid 100 16 256

Remove the # so that the line becomes:

cache_dir ufs /var/spool/squid 100 16 256

Save the file and close the editor.

6. Restart Squid

Run:

sudo systemctl restart squid

7. Enable Squid at Startup

Run:

sudo systemctl enable squid

8. Check Squid Status

Run:

sudo systemctl status squid

Verify that Squid is active (running).

Report Evidence

Take a screenshot showing that the Squid service is active and running.

Part 3 – Configuring Ubuntu to Use the Proxy

9. Open Network Settings

  1. Open Settings.
  2. Select Network.
  3. Locate Network Proxy.
  4. Open the Network Proxy settings.
  5. Select Manual.

10. Configure the Proxy

Configure the proxy as follows:

Setting Address Port
HTTP Proxy localhost 3128
HTTPS Proxy localhost 3128

Apply the settings.

Report Evidence

Take a screenshot showing your Ubuntu Network Proxy configuration.

Part 4 – Generating Web Traffic

11. Open the PDF

Open Firefox and visit:

http://cs.ucmo.edu/~aksoy/teaching/cybr5940/map.pdf

Verify that the PDF opens successfully.

Part 5 – Examining the Squid Access Log

12. Display the Access Log

Return to the terminal and run:

sudo cat /var/log/squid/access.log

13. Locate the PDF Request

Look through the output for the request associated with map.pdf.

Report Evidence

Take a screenshot showing the Squid access log entry associated with map.pdf.

In your report, briefly answer:

What information can you identify in the Squid access log entry for the PDF request?

Part 6 – Locating the PDF in the Squid Cache

14. Switch to the Root User

Run:

sudo su

15. Navigate to the Squid Cache

Run:

cd /var/spool/squid

16. Search the Cache

Search for a cached file containing information about the PDF:

grep -rail pdf

The command should return the location of the cached object containing the PDF.

Record the filename/path that you found. You will use it in the following steps.

Report Evidence

Take a screenshot showing the result of your search and the cached object you identified.

Part 7 – Examining the Cached Object

17. Examine the Beginning of the File

Replace FILENAME with the cache filename you identified:

hexdump -C FILENAME | head

Examine the hexadecimal and ASCII output.

You should be able to identify information associated with the requested PDF.

The cached object contains:

  1. URL information
  2. HTTP headers
  3. File data

Report Evidence

Take a screenshot of your hexdump output.

In your report, identify:

  • The URL
  • HTTP header information
  • Where the file data begins

Part 8 – Finding the HTTP Header/Data Boundary

The actual PDF data begins after the HTTP headers.

HTTP headers and the message body are separated by:

\r\n\r\n

In hexadecimal, this is:

0d 0a 0d 0a

18. Display More of the Cached Object

Run:

hexdump -C FILENAME | head -26

Look for:

0d 0a 0d 0a

Do not worry if the separator appears on a different line than shown in an example. Locate it in your own cached object.

Part 9 – Installing Bless Hex Editor

19. Install Bless

Run:

sudo apt-get install bless

20. Open the Cached Object

Run:

bless FILENAME

Bless will display the contents of the cached object in hexadecimal form.

Part 10 – Carving the PDF

21. Find the Header/Data Separator

In Bless, locate:

0d 0a 0d 0a

Report Evidence

Before modifying the file, take a screenshot clearly showing the separator and the surrounding bytes.

22. Remove the Header Information

Delete everything from the beginning of the cached object through and including:

0d 0a 0d 0a

The remaining data should contain the PDF file.

Report Evidence

Take a screenshot showing the beginning of the remaining data after the header information has been removed.

In your report, answer:

  1. What does 0d 0a 0d 0a represent?
  2. Why is this sequence important when carving the PDF?
  3. What information did you remove from the cached object?

Part 11 – Saving the Carved PDF

23. Save the File

In Bless:

  1. Select File → Save As.
  2. Navigate to your home directory.
  3. Select Desktop.
  4. Save the file as:
carved.pdf

Part 12 – Correcting File Ownership

24. Return to the Terminal

Navigate to your Desktop:

cd ~/Desktop

25. Change the File Ownership

Replace YOURUSERNAME with your Ubuntu username:

sudo chown YOURUSERNAME carved.pdf

Part 13 – Verify the Recovered File

26. Open carved.pdf

Use the Ubuntu Files application to locate:

carved.pdf

Open the file.

If the carving process was completed correctly, the PDF should open normally.

Report Evidence

Take a screenshot clearly showing the successfully opened carved.pdf.

If your PDF does not open, return to the cached object and verify that you correctly identified and removed the HTTP header information.
